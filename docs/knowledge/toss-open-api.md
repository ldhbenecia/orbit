# 토스증권 Open API 사용 방식

미국 주식·국내 상장 ETF 시세를 토스증권 Open API 로 받는다.

> 확인일: 2026-10-04 · 출처: [developers.tossinvest.com/llms.txt](https://developers.tossinvest.com/llms.txt) 가 가리키는 공식 문서 (overview, faq, openapi.json)

## 쓰는 것

| 경로 | 용도 |
|---|---|
| `POST /oauth2/token` | 토큰 발급 (Client Credentials) |
| `GET /api/v1/candles` | 일봉 (`interval=1d`, 최대 200개, `nextBefore` 로 과거 방향 페이지, 수정주가 기본) |
| `GET /api/v1/stocks` | 종목 정보 — 종목코드 확인 |
| `GET /api/v1/market-calendar/KR` | 국내 휴장일·정규장 시각·다음 영업일 (적립일, 다음 개장 추정) |
| `GET /api/v1/market-calendar/US` | 미국 정규장 시각 — 다음 국내 개장 전에 끝날 미국장이 남았는지 |
| `GET /api/v1/exchange-rate` | 원/달러 매매기준율(`midRate`). `dateTime` 으로 과거 시점 조회 (1분 단위 유효 구간) |

엔진은 아래 조회 경로만 부를 수 있게 막아 둠: 캔들, 현재가, 종목 정보, 환율, 국내·미국 장 캘린더

## 안전 — 키 하나로 주문까지 가능

- **조회 전용 키가 없다.** 같은 키에 계좌 헤더(`X-Tossinvest-Account`)를 붙이면 주문·잔고 API 가 열린다
- orbit 은 조회 경로 화이트리스트 밖은 요청 전에 거부하고, 계좌 헤더를 절대 붙이지 않는다 (테스트로 강제)
- 키는 레포 루트 `.env` 에만 (`.env.example` 에 이름만). 설정은 `SecretStr` 이라 출력돼도 가려짐
- **허용 IP 등록 필수** — 등록 안 된 IP 의 호출은 403. 집·카페처럼 IP 가 바뀌면 다시 등록
- 키 만료 2027-10-04 — 만료 전 재발급

## 동작 특성

- 토큰은 클라이언트당 1개만 유효. 새로 발급하면 이전 토큰이 즉시 무효 → 프로세스 안에서 재사용, 만료 60초 전에만 재발급, 401 이면 한 번 재발급 후 재시도
- 호출 한도 (클라이언트 × 그룹별 초당): 캔들 20회, 시세 15회, 종목 정보 5회, 인증 5회, **장 캘린더·환율(`MARKET_INFO`) 3회**. 넘으면 429
  - 클라이언트가 그룹별로 최근 요청을 세어 한도 전에 기다림 (1초 경계에 맞춰 보내도 도착 시각 차이로 걸려서 구간을 1.2초로). 429 는 한 번만 쉬고 재시도
- 현재가(`/prices`)는 **시간외 가격이 섞임** — 정규장 마감 뒤에도 바뀜 (예: QQQ 현재가 시각 뉴욕 금요일 19:59). 확정 종가가 필요하면 일봉을 씀
- 미국 종목 중 토스에 없는 것도 있음 — 옛 심볼(EchoStar `SATS`)은 404, 새 심볼 `ECHO` 로 조회됨
- 가격·거래량은 **문자열**로 와서 `Decimal` 로 그대로 받음
- 미국 일봉 시각도 한국 시간 표기로 온다 — 뉴욕 0시가 여름 `13:00+09:00`, 겨울 `14:00+09:00`. 거래소 시간대로 바꿔서 거래일을 잡음
- 분봉(`1m`)·일봉(`1d`)만 있음. 주봉·월봉은 일봉을 묶어서 만듦 (월요일·1일 시작)

## 토스 밖 출처

| 출처 | 용도 | 주의 |
|---|---|---|
| 미래에셋 TIGER ETF 상품 페이지의 구성 종목(PDF) 표 | TIGER 미국우주테크 구성 종목 비중 | 공개 API 가 아니라 화면용 경로 — 바뀌면 추정이 실패로 표시됨. 하루 한 번만 받음 |
| 미래에셋 TIGER ETF 상품 페이지의 기준가격(NAV) | TIGER 미국S&P500·미국우주테크 기준가 | 화면용 페이지. 당일 장 마감 뒤 그날 기준가가 올라옴. 10분마다만 받음 |
| 한국투자신탁운용 ACE ETF 펀드 정보 (`papi.aceetf.co.kr/api/funds/{펀드코드}`) | ACE 미국나스닥100 기준가(`stpr`)·기준일(`stdDt`, 숫자) | 사이트가 쓰는 API — 공개 문서 없음. 기준가가 하루 늦게 올라옴 |

## 아직 정하지 않은 것

- 토스 주식 수수료·호가 단위 (공식 확인 후 주식 백테스트)
- 공개 사이트 배포 시: Actions 러너는 IP 가 바뀌어 호출 불가, 공개 표시 가능 여부(약관)
