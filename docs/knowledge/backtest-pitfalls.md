# 백테스트 함정 체크리스트

백테스트는 실제보다 좋게 나오기 쉽다. `backtest-review` 스킬이 이 목록을 하나씩 확인한다.

| # | 함정 | 무엇이 문제인가 | 확인 방법 |
|---|---|---|---|
| 1 | 미래 데이터 참조 (look-ahead) | 판단 시점에 몰랐던 정보를 씀. 예: 오늘 종가로 판단하고 오늘 종가에 체결 | 미래 캔들을 바꿔도 과거 판단이 같은지 테스트. 체결은 다음 봉 시가 |
| 2 | 수수료·슬리피지 누락 | 거래가 잦은 전략일수록 크게 과대평가 | 실제 수수료율 + 보수적 슬리피지 포함 여부 |
| 3 | 과최적화 (overfitting) | 과거에 딱 맞춘 파라미터는 미래에 안 맞음 | 근처 파라미터에서도 비슷한지, 검증 기간 분리 |
| 4 | 생존 편향 | 지금 살아남은 종목만으로 과거를 돌림 (상장폐지 종목 누락) | 미국 개별주 유니버스를 과거 시점 기준으로 구성했는지 |
| 5 | 데이터 소스 불일치 | 해외 달러 가격으로 백테스트하고 업비트 원화로 거래 (김치 프리미엄) | 실제 거래할 거래소·통화 데이터인지 |
| 6 | 체결 가능성 무시 | 최소 주문 금액·호가 단위·거래량 부족 | 주문 단위 반영, 소액이라 거래량은 보통 문제 아님 |
| 7 | 짧은 기간 | 한 번의 상승장만 포함된 결과 | 하락장·횡보장이 포함된 기간인지, 구간별 성과 |
| 8 | 기준선 없음 | 수익이 났어도 그냥 들고 있는 것보다 못할 수 있음 | 단순 보유·적립식과 비교 |
| 9 | 수익률만 봄 | 큰 낙폭을 견딜 수 있는지 모름 | MDD, 최장 손실 기간, 거래 횟수 함께 |
| 10 | 데이터 결측·오류 | 빠진 캔들, 비정상 가격, 분할·배당 미반영 | 결측 검사, 수정주가 사용 여부 |
| 11 | 다중 비교 | 전략 50개를 돌려 1등을 고르면 운일 확률이 큼 | 몇 개를 시도했는지 기록 (노트북·일지) |
| 12 | 실행 지연 | 실거래는 봉 확정 후 몇 분 뒤 주문 | 체결 가격 가정이 보수적인지 |
