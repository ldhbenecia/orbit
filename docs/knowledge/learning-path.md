# 학습 경로 — 만들면서 배우기

각 단계는 **만드는 것**과 **배우는 개념**이 짝지어져 있다. 실제 돈은 5단계부터.

| 단계 | 만드는 것 | 배우는 개념 | 상태 |
|---|---|---|---|
| 1 | 업비트 BTC 원화 일봉 수집 + 가격 차트 | 캔들(시가·고가·저가·종가), 일봉 경계, 김치 프리미엄 | ✅ |
| 2 | 단순 보유 · 적립식 백테스트 | 수익률, CAGR, MDD, 기준선 | ✅ |
| 3 | 이동평균 필터 · 변동성 돌파 전략 | 추세추종, 단기 패턴, 수수료 영향 | ✅ |
| 4 | 백테스트 비교 화면 + 함정 점검 | look-ahead, 과최적화, in/out-of-sample, 파라미터 민감도 | ✅ (규칙 검증) |
| 4.5 | 검증 강화 → 새 규칙 | 샤프 비율, 다중 검정(시험 횟수 보정), 변동성 맞춤, 여러 기간 추세 — [연구 목록](research.md) | 진행 중 |
| 5 | 가상 장부 + 리스크 가드 + dry-run 엔진 | 포지션 사이징, 하드 리밋, 대조, 멱등성 | ✅ 코인 |
| 6 | BTC 소액 실거래 | 슬리피지, 실행 지연, 백테스트와 실전의 차이 |
| 7 | 토스 API · 미국 개별주 | 장 시간, 갭, 서머타임 |
| 8 | 미국 개별주 모멘텀 실험 | 팩터, 유니버스, 생존 편향 |

## 핵심 다섯 가지 — 막히면 여기로

1. **수익률보다 최대 낙폭(MDD)** — −50% 가 되면 원금 회복에 +100% 가 필요. 규칙의 가치는 "더 버는 것"보다 "덜 잃는 것"일 때가 많음
2. **백테스트는 과거에 이랬다는 것** — 여러 개를 시험할수록 우연히 좋아 보이는 게 나옴. 그래서 기간 분리·민감도·시험 횟수 보정
3. **비용이 전략을 죽임** — 거래가 잦을수록 수수료·슬리피지가 쌓임
4. **이길 기준은 단순 보유** — 복잡한 규칙이 "그냥 들고 있기"를 못 이기면 쓸 이유가 없음
5. **돈이 걸린 코드는 안전장치가 먼저** — 이중 주문·남의 돈 매도 같은 사고는 전략이 좋아도 한 번에 손실

## 단계를 넘어가는 기준

- 그 단계의 개념을 자기 말로 설명할 수 있다 (일지 "배운 것"에 적기)
- 결과물이 테스트를 통과하고 화면에서 확인된다
