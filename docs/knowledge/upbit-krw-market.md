# 업비트 KRW 마켓 규칙

엔진의 값은 `engine/src/orbit/marketdata/upbit_rules.py` 한 곳에 있다. 거래소가 바꾸면 이 문서와 그 파일을 같이 고친다.

> 확인일: 2026-10-04 · 출처: [업비트 수수료 안내](https://upbit.com/service_center/fees), [거래 이용 안내](https://support.upbit.com/hc/ko/articles/4403838454809)

## 수수료 (부가세 포함, 이벤트에 따라 달라질 수 있음)

| 마켓 | 일반주문 (Maker·Taker 동일) | 예약주문 |
|---|---|---|
| KRW | **0.05%** | 0.139% |
| BTC · USDT | 0.25% (현재 0.05% 인하 이벤트 중) | 0.25% |

- 정산: 매수 = 체결금액 + 수수료, 매도 = 체결금액 − 수수료
- orbit 은 일반 지정가 주문만 쓴다. 예약주문은 수수료가 약 2.8배라 쓰지 않는다
- "테이커 0.15% 인상" 커뮤니티 제보가 있었으나 확인일 기준 공식 표에는 없음. 실거래 단계에서는 계정별 실제 수수료를 주문 가능 정보 API 로 읽어 쓴다

## 주문 금액

| | KRW 마켓 |
|---|---|
| 최소 주문 금액 | 5,000원 (미만은 접수 거부) |
| 최대 주문 금액 | 10억원 |

## 호가 단위 (KRW 마켓, 가격대별)

| 가격 | 호가 단위 |
|---|---|
| 1,000,000원 이상 | 1,000원 |
| 500,000 ~ 1,000,000원 | 500원 |
| 100,000 ~ 500,000원 | 100원 |
| 50,000 ~ 100,000원 | 50원 |
| 10,000 ~ 50,000원 | 10원 |
| 5,000 ~ 10,000원 | 5원 |
| 100 ~ 5,000원 | 1원 |
| 100원 미만 | 0.1원 이하 (orbit 범위 밖) |

지정가는 호가 단위에 맞아야 접수된다. 백테스트는 매수 가격을 올리고 매도 가격을 내려 항상 불리한 쪽으로 맞춘다.

## 일봉

UTC 0시(한국 오전 9시)부터 24시간의 시가·고가·저가·종가.

- 거래가 없던 날은 일봉이 없다 — KRW-ETH 는 2017-10-21 ~ 23 이 비어 있음 (같은 날 KRW-BTC 는 있음). 수집기의 결측일 검사가 경고로 알려줌

## 슬리피지 — 공식 값이 아닌 가정

거래소 규칙이 아니라 "시가보다 얼마나 불리하게 체결될까"에 대한 가정이다.

- 실측 (2026-10-04 일요일 오후, 공개 호가 API): KRW-BTC 1호가 스프레드와 100만~1,000만원 즉시 매수 시 중간가 대비 차이가 모두 0.05% 보다 한참 작았음 (측정값은 시세 데이터라 싣지 않음)
- 백테스트 기본값 **0.05%** — 실측보다 넉넉하게. 시가 근처 변동성으로 스프레드가 벌어지는 경우를 감안한 보수값
- 한 번의 측정이므로 실거래 체결 기록이 쌓이면 실제 슬리피지로 다시 정한다
