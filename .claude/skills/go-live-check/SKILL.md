# 실거래 전환 점검

**이 스킬은 점검만 한다. 실거래 전환·예산 설정·키 입력은 사용자가 직접 한다.** Claude 는 실거래 모드로 엔진을 실행하지 않는다.

## 인자

$ARGUMENTS — 전환할 전략과 자산

## 점검표 (각 항목에 근거 — 파일:줄, 테스트 이름, 로그 기간 — 를 붙여 보고)

### 전략
- [ ] 백테스트 검토 완료 (`backtest-review`), 채택 ADR 존재
- [ ] dry-run 최소 2주 이상, 그 기간 판단이 백테스트 로직과 일치

### 돈 안전장치 ([money-safety](../../rules/money-safety.md))
- [ ] 배정 예산·1회 상한·하루 주문 횟수 상한이 설정에 있고, 각각을 넘는 주문이 거부되는 테스트 통과
- [ ] 사용자 보유분 매도 거부 테스트 통과
- [ ] 타임아웃 후 재주문 안 함 테스트 통과
- [ ] 킬 스위치 → 신규 주문 0 테스트 통과, 대시보드·텔레그램 양쪽에서 동작 확인
- [ ] 시작 시 대조(reconcile) 동작, 불일치 시 정지 확인
- [ ] 지정가만 사용, 시장가 경로 없음
- [ ] 설정 누락 시 dry-run 으로 떨어짐

### 키·환경
- [ ] 업비트 키 출금 권한 없음, 허용 IP 가 서버 IP (사용자 확인)
- [ ] 키는 서버 env 에만, 레포·로그에 없음 (gitleaks 통과)
- [ ] 알림이 실제로 폰에 도착

### 운영
- [ ] 열린 incident 없음
- [ ] 첫 실거래 예산은 정책 문서의 금액 이하

## 마무리

모든 항목 통과 시: 사용자에게 **직접 할 일**(설정 파일에서 모드 변경, 대시보드 확인 문구 입력)을 단계별로 안내하고 끝낸다. 하나라도 미통과면 무엇이 남았는지만 보고한다.
