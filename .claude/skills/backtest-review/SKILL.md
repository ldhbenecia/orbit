# 백테스트 검토

## 인자

$ARGUMENTS — 대상 전략(들)과 기간·자산 (예: `ma-filter vs dca, BTC, 2018-2026`)

## 절차

1. **실행 조건 확인** — 데이터 소스(업비트 원화인지), 기간, 수수료율, 슬리피지, 체결 가격 가정(다음 봉 시가 등), 초기 자본
2. **함정 체크리스트** — [docs/knowledge/backtest-pitfalls.md](../../../docs/knowledge/backtest-pitfalls.md) 항목을 하나씩 확인하고 통과/미확인/위반으로 표시. 위반이 있으면 결과 해석 전에 보고
3. **비교표** — 기준선(단순 보유, 적립식) 포함

   | 전략 | 총수익 | CAGR | MDD | 최장 손실 기간 | 거래 횟수 | 총 수수료 |
   |---|---|---|---|---|---|---|

4. **강건성** — 파라미터 ±20~30% 변경 시 결과, in-sample / out-of-sample 분리 결과, 구간별(상승장·하락장·횡보장) 성과
5. **쉬운 해설** — 비전문가용 3~5줄. 숫자를 금액으로 풀어서 (예: "100만원이 최악의 순간 62만원까지"). 과장 금지: "과거에 이랬다"로 서술
6. **결론 형식** — 채택 후보 / 기각 / 추가 실험 필요 중 하나와 이유. 채택은 사용자가 결정하고, 결정되면 `new-decision` 으로 ADR
7. 산출물은 `reports/` (gitignore). 결론 요약은 노트북 상단이나 일지 "배운 것"에
