# 코드 주석

주석은 다음에 이 코드를 읽고 고칠 사람을 위한 것

## 무엇을 쓰나

**코드만 봐서는 알 수 없는 것만**

- 왜 이렇게 했는지 — 다른 방법을 쓰면 무엇이 깨지는지
- 지켜야 하는 조건 — 순서·같이 바꿔야 하는 곳
- 도메인 규칙 — 거래소 규칙(호가 단위, 최소 주문 금액), 예산 격리, 미래 데이터 금지 등

## 쓰지 않는 것

- 코드를 한국어로 다시 읽어 주는 설명
- 개발 과정 이야기 (검토 경위, 이전 구현 비교) — 커밋·PR·ADR 에
- 내부 문서 번호 (ADR·plan·이슈 번호) — `docs/` 내부 문서는 공개 레포에 없음

## 형식

- 한두 줄, 명사형 종결(`~함`, `~됨`), 끝 마침표 X
- 필드 설명은 그 줄 옆 `#` 로

```python
# ✅
min_order_krw: Decimal  # 업비트 원화 마켓 최소 주문 금액

# ✅
# 타임아웃은 실패가 아니라 불명 — 조회로 확정 전 재주문하면 이중 주문 가능
```
