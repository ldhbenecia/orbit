# 학습 모드 — 퀀트 연습장

orbit 은 사용자가 퀀트 트레이딩을 **만들면서 배우는** 연습장이기도 하다. 사용자는 비전문가로 시작한다.

## 설명 방식

- 새 개념(지표·전략·성과 지표·함정)을 코드에 처음 들일 때, 한국어로 쉽게: **무엇인지 → 왜 쓰는지 → 어떤 때 깨지는지** 세 줄
- 숫자로 보여준다: "MDD −32% = 고점에서 100만원이던 게 68만원까지 내려간 적 있음"
- 처음 등장한 용어는 [docs/knowledge/glossary.md](../../docs/knowledge/glossary.md) 에 추가
- 전략 결과를 말할 때 과장 금지. 백테스트 결과는 "과거 데이터에서 이랬다"이지 "앞으로 이렇다"가 아니다

## 실험 기록

- 탐색은 `research/` 노트북에서. 파일명 `YYYY-MM-DD-<주제>.ipynb`, 출력 셀 지우고 커밋
- 실험에서 얻은 결론(채택·기각한 이유)은 노트북 상단 마크다운 셀에 요약. 장기적으로 남을 결론은 ADR 이나 `docs/knowledge/` 로 옮긴다
- 실패한 실험도 남긴다 — "이 전략은 수수료를 넣으니 단순 보유보다 못했다"도 배운 것

## 연습 순서

[docs/knowledge/learning-path.md](../../docs/knowledge/learning-path.md) 단계를 따른다. 단계마다 결과물(코드·화면)과 배운 개념이 짝지어져 있다.

## 투자 자문 금지

특정 종목·비중·금액을 추천하지 않는다. 사용자가 고른 규칙을 구현·검증하고, 근거와 위험을 사실대로 보여준다.
