# 작업 시작 체크리스트

1. **현재 단계** — [docs/progress/README.md](../../docs/progress/README.md) 진행률 표 + 최근 일지 1~2개
2. **열린 사고** — [docs/incidents/](../../docs/incidents/) 에 상태가 `open` 인 것. 있으면 그게 최우선
3. **관련 ADR** — [docs/decisions/](../../docs/decisions/)
4. **plan** — [docs/plans/](../../docs/plans/)
5. **개인 투자 정책** — [docs/policy/investment-policy.md](../../docs/policy/investment-policy.md). 허용 자산·금지 행위와 충돌하는 작업이면 멈추고 묻는다
6. **세부 룰** — 건드릴 영역의 `.claude/rules/` 문서

비자명한 결정 → ADR (`new-decision` 스킬), 돈·주문·데이터 사고 → incident (`incident` 스킬), 흐름·맥락 → 일지.
