# 웹 대시보드 컨벤션 (`web/`)

## 스택

- Next.js (App Router) + TypeScript + Tailwind + shadcn/ui
- 폰트: Pretendard
- 차트: 가격·매매 표시는 lightweight-charts, 일반 차트는 Recharts
- API 타입: FastAPI OpenAPI → `openapi-typescript` 로 생성. 응답 타입을 손으로 다시 쓰지 않는다
- 패키지 매니저: pnpm

## 화면의 주인공

대시보드는 **내 자동매매 지갑**을 보는 곳 — 예산·보유분·손익·매매 기록·판단 근거가 중심이다.

- 시세 분석 기능(분봉, 보조지표, 호가, 다종목 비교)은 만들지 않는다. 그건 거래소 앱이 더 잘함
- 차트는 일봉 하나. 전략 판단 근거와 **내 매수·매도 시점 표시**를 보여주는 보조 수단
- 새 화면·기능을 넣기 전 자문: "내 지갑과 전략을 이해하는 데 필요한가?"

## 디자인 원칙

참고는 토스·애플의 **원칙**까지. 토스 TDS 컴포넌트·피그마 킷·토스 서체, 애플 SF 폰트는 라이선스상 쓰지 않는다.

- 한 화면에 한 메시지. 가장 중요한 숫자를 가장 크게
- 쉬운 문장: "120일선 위라서 계속 보유" 처럼 판단과 근거를 말로. 전문 용어는 툴팁으로 풀이
- 상태는 항상 보이게: dry-run / 실거래, 엔진 실행·정지, 예산 사용률은 상단 고정
- 숫자: `tabular-nums`, 통화 단위 명시, 손익 색은 의미에만 (수익·손실). 장식용 색 금지
- 모션은 절제: 상태 변화를 알리는 데만. 애플 HIG 의 반응성·연속성 원칙 참고 (`apple-design` 스킬)
- 모바일 우선 (폰에서 가장 많이 봄), PWA

## 조작 권한

- 즉시 가능: 전체 정지, 전략 일시정지, 한도 **낮추기**
- 확인 문구 입력 필요: dry-run → 실거래, 한도 **올리기**, 예산 변경
- 만들지 않음: 수동 매수/매도 버튼 (수동 매매는 증권사·거래소 앱에서)
- 대시보드는 사설망(Tailscale 등) + 로그인 뒤에만 노출
