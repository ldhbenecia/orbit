# 시간 · 장 시간 규칙

사용자는 한국에 있다고 단정하지 않는다. 시간은 세 종류로 구분한다.

| 종류 | 기준 | 예 |
|---|---|---|
| 저장 | **UTC** (`datetime` 은 항상 tz-aware) | DB 의 주문 시각, 캔들 시각 |
| 장 경계 | **거래소 타임존** (`zoneinfo`) | 미국장 개장·폐장, 업비트 일봉 경계 |
| 표시 | 사용자 로컬 타임존 | 대시보드, 알림 문구 |

## 규칙

- naive `datetime` 금지. `datetime.now()` 대신 `datetime.now(UTC)`
- 오프셋 하드코딩 금지 (`+9`, `-5` 등). 서머타임은 `zoneinfo` 가 처리하게 둔다
- 미국장: `America/New_York` 기준 09:30–16:00. 휴장일·조기 폐장은 거래소 캘린더로 판단 (요일만 보고 판단하지 않음)
- 업비트 일봉: UTC 00:00 에 봉이 끊긴다. 일봉 기반 전략은 그 직후, 봉 확정을 확인한 뒤 실행
- 스케줄은 "거래소 기준 시각"으로 정의하고, 표시할 때만 로컬로 변환
- 새 날짜 로직을 쓸 때 자문: "이게 특정 타임존을 가정하나?"
